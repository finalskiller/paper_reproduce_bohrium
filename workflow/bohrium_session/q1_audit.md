## 1. 被审计声明（玻尔回答原文摘录）

> "若看力的矢量大小而非系数，|4d/(Z(1+d²)²)| 也是有界的：在 **d=1/3** 处取极大值 **≈1.30/Z**，此后按 1/d³ 衰减（这一极值位置是我对该式的直接求导结果，论文未给出）。"

拆成三个可独立判定的子命题：

| 编号 | 子命题 | 判定 |
|---|---|---|
| S1 | 幅值函数 \|4d/(Z(1+d²)²)\| 在 d=1/3 处取极大值 | **错**（真实极大值在 d=1/√3≈0.577） |
| S2 | 极大值 ≈ 1.30/Z | **对**（精确值 9/(4√3)·(1/Z) = 3√3/(4Z) ≈ 1.2990/Z） |
| S3 | 此后按 1/d³ 衰减 | **对**（大 d 时 ∝ d/d⁴ = d⁻³） |

注：玻尔在回答中明确标注"这是我的求导结果，论文未给出"——来源区分意识正确，但求导结果 S1 错、S2 对。

## 2. 独立推导（可重算）

幅值函数（取 Z=1，Z 是全局归一化常数不影响极值位置）：

```
f(d) = 4d / (1+d²)²
f'(d) = 4·[(1+d²)² - d·2(1+d²)·2d] / (1+d²)⁴
      = 4·(1+d²-3d²) / (1+d²)³
      = 4·(1-3d²) / (1+d²)³
```

驻点：`1-3d² = 0 ⇒ d = 1/√3 ≈ 0.5774`（唯一驻点，d>0；f(0)=0 且 f(∞)=0，故为全局极大值）。

精确峰值：`f(1/√3) = 4·(1/√3) / (4/3)² = (4/√3)·(9/16) = 9/(4√3) = 3√3/4 ≈ 1.29904`。

数值复核（网格 10⁵ 点）：峰值位置 0.57735、峰值 1.29904——与代数一致。

## 3. 反例的定量影响（如果读者照抄）

在玻尔声称的位置 d=1/3 处：`f(1/3) = 4·(1/3)/(10/9)² = 81/50·(1/1.2346) = 1.0800`。

- d=1/3 处 f 仍处于**上升段**（1/3 < 1/√3），即"取极大值"的定性判断也错；
- 若读者把 d=1/3 当作峰值位置引用，会把峰值幅值**低估 20.3%**（1.0800 vs 1.29904）；
- 影响场景：把该极值位置用于解释"斥力在何处最强"或构造优化步长上界的论证。
